## 已实现

| 项目 | 现在的行为 |
|---|---|
| 双引擎应用 | 前端默认自动分配 Xray / Sing-box；单引擎放入诊断选项并明确另一引擎会停止。 |
| 配置切换 | 统一协调器串行切换，两个候选先离线预检；启动或入站探测失败后恢复上一次配置文件及运行模式。返回 revision、失败原因和回滚结果；配置文件通过临时文件替换。 |
| Smart Deploy | 接入统一激活流程和现有 ACME 服务；预设凭据作为 Client 持久化，入站与 Client 同事务创建和删除；QUIC 使用编辑器、订阅与探测共用的 TLS 格式；成功页提供真实订阅地址。 |
| 流量身份 | 两个引擎使用 zc:<client-id> 标识客户端；实时统计保留 client_id / inbound_id。同名 email 不再互相覆盖或重复加配额；旧 email 计数仅在唯一匹配时归属。 |
| 写入与查询 | 出口日志待写入、重试和处理中总容量受限，事务最多 32 个目的地；重试保留原始时间桶。配额计数按小批提交，仅重试未提交部分。WAL 使用独立只读连接池；主要流量查询支持取消和 5 秒期限，CSV 明细最多 20,000 行并返回上限响应头。 |
| 会话撤销 | 管理员 session_version 与登录时间写入 JWT；修改密码、启停 2FA、退出全部设备撤销旧会话。刷新保留原始登录时间，绝对寿命 7 天。安全更新使用比较并更新，恢复码消费避免并发重复使用。 |
| OTA | 新增 ctl ready 和受保护的 /proxy/readiness；候选连续三次就绪才移除旧容器。回滚检查命令结果与旧面板数据库健康；恢复失败明确标记 rollback_failed。辅助容器共享原数据卷保存状态，不依赖故障容器运行 docker exec。 |
| 界面与维护 | 更新页刷新后恢复状态，离开页面停止轮询；进度与错误分开。公共确认框补 dialog 语义、焦点约束、Escape、关闭后焦点恢复。修正安全扫描 job 的 embed 前置资源及中英文 Docker 启动端口；Docker SDK 改用当前构造函数。 |
| 可观测性 | 增加堆内存、goroutine、出口待写入/重试/丢弃指标，以及 /traffic/egress/status。 |

## 验证及边界

- Go 全量测试与项目 golangci-lint 检查；前端 18 项测试、TypeScript 检查和生产构建。
- 升级 helper 使用实际 POSIX shell 执行，Docker 命令由测试替身注入：正常提交、候选不就绪、启动失败、旧容器启动失败、重命名失败、旧容器删除失败，共六种场景。
- 新增运行时预检失败、启动失败、探测失败、回滚失败和取消等待测试；同名客户端、写入失败后精确重试、查询取消、WAL 写事务期间读取已提交值等测试。
- 本机 Docker daemon 不可用，未运行真实容器 OTA、真实代理客户端链路、ACME 签发或 VPS 压测。shell 测试不等于 Docker 实机验收。
- 本机没有可用 CGO / C 编译器，go test -race 未能启动；应在 Linux CI 执行。未做浏览器端 375px / 桌面键盘实测。
- 旧配置按 email 计数的用户，重新应用后才切换到 ID。失败重试存在进程内存中，进程崩溃仍可能丢失尚未落盘的增量；容量上限会丢弃新的目的地日志，但不以此裁剪配额计数。
- 当前运行时 revision 是已生成配置的摘要；待应用提示仍属当前页面状态，尚未实现持久化的配置草稿与版本历史。切换期间已有代理连接可能中断。
- 就绪探测验证进程、监听和可支持的 TLS 阶段，QUIC 探测不等于真实客户端完成协议认证与外网访问。回滚旧镜像兼容使用原有 status，报告的是容器和数据库健康，不能替代旧代理的完整端到端验收。
- ACME 复用现有签发器，其内部网络流程并未完整改造为可随请求取消。
